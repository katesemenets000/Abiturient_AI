# Abiturient_AI

AI-помощник для абитуриентов, который помогает определить образовательные интересы пользователя и подобрать подходящие направления и образовательные программы.

## О проекте

Проект направлен на разработку диалогового ИИ-помощника, который анализирует ответы абитуриента, определяет соответствующие образовательные направления и помогает подобрать подходящие программы обучения.

Система использует LLM для интерпретации ответов на естественном языке, а Python — для управления логикой диалога, обработки результатов и дальнейшего сопоставления с образовательными программами.

## Технологии

- Python
- GigaChat API
- Git / GitHub
- CSV

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Основной файл проекта. Проверка подключения к GigaChat и базовое взаимодействие с моделью. |
| `test_model.py` | Тестирование модели GigaChat-2 на подготовленных примерах. |
| `test_model_pro.py` | Тестирование модели GigaChat-2-Pro. |
| `test_model_3_pro.py` | Тестирование модели GigaChat-3-Pro. |
| `test_all_models.py` | Скрипт для запуска и сравнения нескольких моделей в рамках тестирования. |
| `test_cases.py` | Набор тестовых ответов абитуриентов и ожидаемых кластеров для оценки результатов моделей. |
| `evaluate_results.py` | Скрипт анализа результатов тестирования моделей. |
| `model_comparison.csv` | Таблица сравнительных результатов моделей. |
| `evaluation_details.csv` | Детальные результаты оценки отдельных тестовых случаев. |
| `evaluation_summary.csv` | Сводные результаты тестирования. |

## Принцип работы

1. Абитуриент отвечает на вопросы о своих интересах, предпочтениях и склонностях.
2. GigaChat анализирует свободный текст и сопоставляет его с образовательными кластерами.
3. Результат интерпретации передается программной логике проекта.
4. Python обрабатывает результаты и в дальнейшем используется для расчета баллов и подбора образовательных программ.

## Образовательные направления

В проекте используется система из 12 образовательных кластеров, объединяющих программы по тематическим направлениям и интересам абитуриента.

## Текущий этап разработки

- Подключение к GigaChat API.
- Тестирование различных версий моделей.
- Подготовка тестового набора ответов.
- Оценка качества интерпретации ответов.
- Сравнение результатов моделей.
- Разработка логики будущего помощника.
